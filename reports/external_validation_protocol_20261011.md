# Prespecified external MRI evaluation — 11 October 2026

The cohort, primary pipeline, budgets, endpoints and component-rule ablation were
specified before the MSLesSeg prediction pilot. This is a local prespecification,
not a public registered protocol. Subsequent reporting clarifications are listed
below. The study tests transfer of the reconstructed image-only pipeline; it
does not establish that the original manuscript's historical MRI results were
generated by that pipeline.

## Dataset choice and access

Choose **MSLesSeg** as the first external cohort. Its public processed release
contains FLAIR images and expert-reviewed MS lesion masks in the same registered
space. FLAIR matches the existing input modality, and dispersed lesions challenge
the original single-largest-component assumption. The official deposit is
https://doi.org/10.6084/m9.figshare.27919209 and the dataset paper is
https://doi.org/10.1038/s41597-025-05250-y. The deposit declares CC BY 4.0.

Download the complete official deposit, retaining archive sizes, supplied MD5,
computed checksums, source metadata and original files. Use the provided processed
images/masks for the primary evaluation. Authors report FSL FLIRT registration to
MNI152 at 1 mm isotropic resolution and BET brain extraction. This is supplied
dataset preprocessing, not an experiment demonstrating our registration method.
Raw images and supplied transforms are preserved for subsequent work.

## Cohort and independent observational units

Inventory all available FLAIR/reference pairs using filenames and metadata alone.
The release describes **115 series from 75 patients**. Evaluate every usable pair,
including both official partitions, with no training or tuning on either.
For the primary independent-patient analysis, take the earliest available numeric
timepoint per patient. Report remaining longitudinal sessions separately; do not
count timepoints or random seeds as additional patients. No case is excluded for
poor predictions, small lesion size or undesirable overlap.

If a source file is missing, corrupt or geometrically invalid, record the failed
case and reason. Do not silently alter the cohort. References must have declared
valid values and matching spatial geometry. Any necessary evaluation-only
nearest-neighbour mapping must be recorded explicitly after predictions, never
used to tune predictions.

## Frozen primary pipeline

Keep the reconstructed BraTS protocol unchanged: finite nonzero image foreground,
1st/99th percentile normalization; gamma/contrast enhancement with the original
contrast/departure/saturation objective; histogram-based three-class Otsu
segmentation; highest-intensity class; largest six-connected component.

Compare original EHO, modified EHO, PSO, GA and the documented ACOR-inspired method
with **seeds 0, 1, 2; 1,500 counted objective evaluations per stage; population 30**.
Also run the deterministic direct multilevel-Otsu baseline. Labels never enter
normalization, image selection, enhancement, threshold search or component choice.
For each case, save all predictions before opening its reference mask.

Save native-grid binary predictions, representative enhanced volumes, parameters,
complete objective histories, measured stage time and sampled process RSS, source
hashes, environment and per-case records. Report training requirement as none for
these methods; this does not imply lower cost than an unmeasured learned model.

## Prespecified diagnostic ablation

For modified EHO and direct Otsu, also evaluate the highest-intensity class with
**all components retained**. This is a separately named component-rule ablation,
not a correction substituted for the frozen primary result. No lesion labels
determine component thresholds or retained regions. Its purpose is to determine
whether a single-largest-component rule discards dispersed lesions.

## Accuracy, uncertainty and inference

Compute Dice, IoU, precision, recall, confusion counts and lesion-volume error from
saved full-resolution masks. Report within-session mean and sample SD across
seeds. For primary comparisons, average seeds within each patient's earliest
session, then aggregate across patients; report mean, SD, median and bootstrap
95% confidence intervals using 5,000 patient resamples with seed 20261011.

For paired method comparisons against modified EHO, report mean paired Dice
difference, a paired bootstrap interval, two-sided Wilcoxon signed-rank p-value
and Holm adjustment across those comparisons. A non-significant p-value is not
proof of equivalent performance. Reference-empty cases and undefined precision
must be counted and represented explicitly.

Compare speed with image quality and objective quality. RSS is a sampled process
measurement, not exact allocator peak or hardware energy cost. No learned model
or clinical endpoint is introduced in this execution stage.

## Additional studies

Use the earliest sessions of the first three numeric patient IDs, fixed without
inspecting labels, for two separate studies:

1. Known rigid perturbations of an anatomical MRI slice using the existing
   registration convention, five seeds, five optimizers and 1,500 evaluations.
   This is a controlled registration stress test, not interpatient or clinical
   registration validation.
2. Controlled Gaussian corruption of normalized image-only slices at standard
   deviations 0.03 and 0.08, corruption seeds 0/1/2. Evaluate the frozen contrast
   methods against the known uncorrupted image, noisy identity and a fixed
   Gaussian smoothing control. The clean image is withheld from optimization
   and used for evaluation only. Synthetic noise is not a clinical clean/noisy
   reference pair.

## Visualization and claim comparison

Produce an interactive_prediction_reference.html viewer with separate supplied
reference and predicted lesion surfaces. Call references MS lesions, never
tumours or newly detected disease. Preserve affine coordinates and millimetre
units; evaluate full-resolution masks independently of display meshes. Reference
meshes always use stride 1 so that isolated small lesions remain visible.
Prediction meshes request stride 2, with a stride-1 fallback if display sampling
erases a nonempty mask; record the actual display choices.

Volumes in millilitres are measured on the supplied 1 mm registered grid. The
authors' affine mapping to MNI152 can change physical volume relative to the raw
acquisition, so these values are not native-acquisition lesion burden or a
validated clinical burden estimate. Prediction and reference use the same grid.

Compare measured outcomes with the original manuscript, rewritten draft and
existing BraTS rerun reports. Distinguish failure of the optimizer from mismatch
between its intensity objective and lesion anatomy. Do not replace unfavorable
external results with favorable cases or claim general clinical accuracy,
diagnostic readiness, reconstruction fidelity or ML superiority.
## Reporting clarifications, 11 October 2026

After the pilot, documentation was clarified to distinguish reference display
stride 1 from prediction display stride 2 and to identify volume measurements as
supplied registration-grid volumes. After code review, the inherited primary ROI
SSIM mask was identified as repeated cross erosion rather than square-window
erosion, and postsearch verification calls in the ancillary studies were
distinguished from search-budget calls. None of these qualifications changes the
frozen prediction functions, evaluation cases or unfavorable measurements.

The MRI optimization decision space has two parameters per stage (gamma/contrast
or the two Otsu thresholds); the separate rigid study has three transformation
parameters. Image voxel count is not the optimizer's decision dimension. This
cohort therefore does not constitute a high-dimensional-search validation.
