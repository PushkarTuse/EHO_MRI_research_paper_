# MSLesSeg Repository

This repository contains the following items:

- **MSLesSeg Dataset.zip**: The dataset including the masks.
- **MSLesSeg_RAW.zip**: The raw MRI files.
- **MSLesSeg-2024-main.zip**: The code to reproduce the preprocessing performed on the raw files.

## Description

The MSLesSeg repository provides access to a valuable MS lesion segmentation dataset along with the necessary code to replicate the preprocessing steps. The dataset includes both preprocessed MRI scans with corresponding lesion masks and the original raw MRI files, as well as the associated .mat files containing the transformation parameters needed to enable accurate remapping of the segmentations back onto the original images. By providing these files, researchers can experiment with alternative preprocessing pipelines, compare methods, and develop new segmentation algorithms.

## Contents

- **MSLesSeg Dataset.zip**  
  Contains the preprocessed dataset with lesion masks.

- **MSLesSeg_RAW.zip**  
  Contains the original raw MRI files.

- **MSLesSeg-2024-main.zip**  
  Contains the code used to reproduce the preprocessing performed on the raw files.

- **mat_files.zip**
  Contains the .mat files with transformation parameters.

## Getting Started

1. **Download the Files**  
   Download and unzip the following files:
   - MSLesSeg Dataset.zip
   - MSLesSeg_RAW.zip
   - MSLesSeg-2024-main.zip
   - mat_files.zip

2. **Reproducing Preprocessing**  
   To reproduce the preprocessing, refer to the code in the `MSLesSeg-2024-main.zip`. Follow the instructions provided in the code documentation to process the raw MRI files.

3. **Usage**  
   Use the preprocessed dataset and lesion masks for segmentation research and related projects. The raw MRI files are provided to allow for alternative or further processing if needed.
